# Actividad GitHub - Unidad 1

**Estudiante:** Jefferson Rojas

## Descripción

Este repositorio corresponde a la actividad de la Unidad 1 sobre la creación y gestión de un repositorio en GitHub.

El objetivo es familiarizarse con el uso de sistemas de control de versiones mediante la creación de un repositorio, la incorporación de un archivo README y la realización del commit inicial.

## Contenido

- `README.md`: información general de la actividad.
- `hola_github.py`: programa básico utilizado como archivo de prueba para el repositorio.

## Objetivo

Familiarizar al estudiante con el uso de sistemas de control de versiones mediante la creación y gestión de repositorios.
